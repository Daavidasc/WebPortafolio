\# AGENTS.md



\## Proyecto



Portafolio personal de David Serrudo construido con React, Vite, TypeScript

y Tailwind CSS.



\## Reglas visuales



\- Usar negro, blanco, grises y un único acento naranja rojizo.

\- Máximo dos familias tipográficas.

\- Mantener una estética editorial, minimalista y tecnológica.

\- No añadir tarjetas, gradientes, badges o secciones no solicitadas.

\- No inventar experiencia, métricas, clientes ni proyectos.

\- Utilizar las imágenes de `references/` como orientación visual.

\- Las imágenes de referencia no deben aparecer en producción.



\## Código



\- Crear componentes pequeños y reutilizables.

\- Mantener el contenido personal separado de la presentación.

\- Evitar estilos inline.

\- No instalar dependencias sin justificarlo.

\- Mantener TypeScript sin errores.

\- Ejecutar `npm run lint` y `npm run build` después de cambios importantes.



\## Responsive



\- Probar escritorio, tablet y móvil.

\- No permitir overflow horizontal.

\- Los elementos flotantes nunca deben cubrir textos o botones.

\- Respetar `prefers-reduced-motion`.



\## Finalización



Una tarea está completa cuando compila, funciona, es responsive y ha sido

revisada visualmente.
